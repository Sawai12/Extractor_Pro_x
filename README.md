## 📋 ABOUT THE PROJECT

Extractor Pro X is a Telegram-based TXT extraction bot built with Python + Pyrogram. It provides a simple and automated workflow for processing TXT files directly through Telegram. The project is designed with a modular structure and can be configured and run on Termux or other compatible Python environments.
